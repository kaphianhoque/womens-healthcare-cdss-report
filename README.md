# AI-Integrated Women's Healthcare Management System with Explainable Breast Cancer Clinical Decision Support

Phase 01: Project Plan

**Authors:** Kaphian Hoque, Farahnaz Safari, Parniyan Ibrahimi

## Overview
A web-based Women's Healthcare Management System integrating core healthcare 
administration (patient registration, appointment scheduling, EMRs, prescriptions) 
with an AI-assisted Clinical Decision Support System for breast cancer screening 
from ultrasound images. Uses DenseNet121 for image classification and Grad-CAM 
for explainability. Built on a layered architecture with RESTful APIs, JWT 
authentication, and RBAC.

## Contents
- `main.tex` — Report source (LaTeX)
- `images/`, loose `.jpeg`/`.png` files — Figures referenced in the report
- `.pdf` files — Diagrams and analysis charts (Gantt, cost estimation, slack time, etc.)

## Compiling
Compile `main.tex` with a LaTeX engine that supports PDF image inclusion
